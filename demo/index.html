Second Slide

Check the bottom left corner for the plugin indicator. It sits in an anchor from positionTools.addAnchor, so it stays there in scroll view too.

A slide the other way round

The indicator follows it. addThemeColor asks the theme for its two text colours and keeps --c-theme-color on the deck, so a plugin that puts something over the slides does not have to hardcode one.

While a slide like this is showing, the deck also has the class c-theme-inverted.

No indicator here

This slide has data-state="no-indicator", and the plugin's CSS hides the indicator for it. Reveal applies the state in the regular view; stateTools.addSlideStates does it in scroll view.
